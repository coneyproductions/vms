# WPORG Release Notes 1.3.6

## Identity

- Public plugin: `Backstage Venue Manager`
- Public slug and text domain: `backstage-venue-manager`
- Public version: `1.3.6`

## Summary

Version 1.3.6 includes eligible Backstage Outreach Guest Pass claimants in the
existing post-event feedback recipient selection. Claims are matched to their
recorded Event Plan, invalid or canceled reservations are excluded, and normalized
email addresses are deduplicated across ticket and complimentary sources.

The release does not change paid-ticket eligibility, survey content, sending
controls, authentication, authorization, ticketing, checkout, claims, admissions,
or inventory behavior. Backstage Outreach remains a separately packaged optional
companion, and no database migration is introduced.
