## Event Credit / Rain Check Direction

Cancellation workflows should support an optional customer Event Credit path without replacing refunds. Preferred language is “Event Credit,” not “rain check.” Customers should always retain a refund path when they paid for an event they did not receive. Event Credits should be auditable, tied to the original event/order/customer, optionally emailed, redeemable toward eligible future events, and reportable as outstanding liability until redeemed/expired/voided.

## Agreement / Contract / Proposal Planning — added 2026-04-25

- Premium add-on direction: formal agreement/contract packet generation should live in `vmsx-agreements`, but the shared booking facts should live in core.
- Core should expose cancellation policy profiles, Event Plan booking-term snapshots, event viability thresholds, clause status/bypass audit, deposits, rider upload/review state, and no-show/nonperformance review data.
- Proposal should include the plain-English guided walkthrough and acknowledgements. Final agreement should stay clean/formal and link back to the accepted proposal version.
- Acknowledgements should visibly show audit details to the vendor: acknowledged date/time, identity, IP address, proposal version, and acknowledgement ID.
- Clause bypass is allowed for proven/high-draw vendors, but only with visibility, reason capture, permission guardrails, timestamp, approver, Event Plan snapshot, and version history.
- No-show handling should avoid default flat penalties. Use documented direct costs, reasonable cover costs, payment withholding where applicable, future booking consequences, and formal notice workflow.
- Add core deposit support separate from base pay/guarantee/bonus/agent fee, with refundable/nonrefundable/creditable and cancellation/no-show treatment.
- Add Technical Rider and Hospitality Rider uploads in the vendor portal. Uploads are requests unless accepted by the venue in writing; approved riders may become agreement exhibits.
- Canonical outline: `docs/12-agreement-contract-roadmap.md`.
