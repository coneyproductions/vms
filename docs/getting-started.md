# Getting Started

This guide walks through installing VMS Core and verifying it is working.

## Install

- Upload the VMS plugin zip or place the `vms/` folder in `wp-content/plugins/`
- Activate **VMS** in WordPress → Plugins

## First-time sanity check

- Confirm you can see the VMS menu in the left admin sidebar
- Open **VMS → Docs** (this page) to confirm the docs system is online

## Concepts

- **Event Plan**: the internal planning record for an event date
- **Vendor / Performer**: an artist or vendor you can assign to an event plan
- **Venue**: a location where an event plan can occur
