# WPORG Release Notes 1.3.5

## Identity

- Public plugin: `Backstage Venue Manager`
- Public slug and text domain: `backstage-venue-manager`
- Public version: `1.3.5`

## Summary

Version 1.3.5 restores configurable Amenities presentation in the Progressive
ticket interface. Event Plan heading/subtext overrides again take precedence over
saved global values and built-in fallbacks. Saved add-on help text, configurable
heading color with readable contrast, and initial expansion are restored while
manual visitor collapse state survives re-enhancement.

The release does not alter ticket, rental, cart, checkout, claim, inventory,
pricing, quantity, or eligibility semantics and does not introduce a schema
change. Backstage Outreach remains a separately packaged optional companion.
