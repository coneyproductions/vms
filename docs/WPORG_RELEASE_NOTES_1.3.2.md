# WPORG Release Notes 1.3.2

## Identity

- Public plugin: `Backstage Venue Manager`
- Public slug and text domain: `backstage-venue-manager`
- Public version: `1.3.2`
- Separate optional companion: `Backstage Outreach 1.1.0`

## Summary

Version 1.3.2 adds reusable-business Guest Pass integration points and improves Guest Pass administration with combined filters, deterministic pagination, complete matching CSV exports, referring-business attribution when the separately installed companion is active, and local complimentary-pass printing.

The companion remains outside the public BVM package. Ordinary Guest Pass claim, admission credential, check-in, cancellation, and existing quick-print behavior remain BVM-owned. This note does not authorize production deployment, publication, WordPress.org submission, or external communication.
