# Phase 4A deterministic Google provider acceptance

`integration.php` loads the accepted Phase 3D authority foundation, then intercepts the actual WordPress HTTP transport used by the Google integration. `fake.php` persists synthetic calendars/events in a private file using an OS file lock, so independent workers share remote state. `concurrency.php` exercises worker exclusion, kill/restart, remote success/local persistence failure and task mutations during delivery. `worker.php` is the independent process entry point. No real Google credentials are required or used.

Run only with the hard-bound disposable bootstrap and database resource supervisor described in `tests/staff-tasks/README.md`. The exact installation runner is retained at `/Users/treyconey/Documents/BVM Ecosystem Audit 2026-09-07/phase-4a/run-disposable.py`; it uses the existing disposable WordPress/WooCommerce/TEC sources and `scripts/lib/bvm-disposable-db.py`. `BVM_GOOGLE_FAKE` must name a file under that private evidence root. All non-fake HTTP and all mail are intercepted before WordPress bootstrap. The fake independently reads MySQL to prove committed task existence and durable attempt intent before remote event writes.

The fake models operation identity, ownership, targeted patching, errors and ETags. It cannot certify Google's real consent UI, actual scope issuance, calendar visibility, event tombstone restoration, token lifetime or inbox/calendar-client behavior. Those require the real-account acceptance checklist in the report. Never point this test at normal Local or another real database.

`php tests/staff-tasks-google/remote-representation.php` runs 16 transport-free assertions for representations observed during real Google acceptance: equivalent UTC/offset instants, omitted default opacity, strict IANA-zone/ownership fields, invalid values, fractional precision and DST folds. This supplements the 451-assertion supervised workflow suite. See `docs/staff-tasks-phase4a/local-acceptance.md` for the completed real-account gate and correction evidence.
