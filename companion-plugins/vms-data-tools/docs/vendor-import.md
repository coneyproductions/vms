# Vendor CSV Import

This guide explains how to import vendors into VMS using a CSV file.

## Before you start

- VMS Core must be active
- VMS Data Tools must be active

## Steps

- Go to VMS → Data Tools → Vendor Import
- Upload your CSV
- Map fields if prompted
- Run import

## Troubleshooting

- If vendors do not appear, confirm required columns are present
- If the import stalls, check PHP upload size and timeout settings
