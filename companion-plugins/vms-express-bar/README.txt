VMS Express Bar standalone add-on for BVM/VMS + WooCommerce.

Provides a dedicated public Express Bar page with event-safe current/next resolution, visual event identity and switching, admission-awareness safeguards, category accordions, age-gated ordering, one-shot WooCommerce handoff, event-scoped order metadata, optional Express-Bar-only checkout tips, relative default ordering windows, show-scoped Current, Completed, Past / Unclaimed, and Future fulfillment views, browse-only mode outside the ordering window, and the unified post-ticket Order Drinks handoff.
